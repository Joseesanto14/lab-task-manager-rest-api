== Introdução
Esta documentação detalha a API REST de Gerenciamento de Tarefas (Task Manager), fornecendo informações sobre requisições, payloads e respostas dos endpoints disponíveis.

== Modelo de dados

=== Task
Uma tarefa é a estrutura principal do sistema, composta por um identificador único, título, descrição opcional e status.

|===
| Campo | Tipo | Descrição

| `id`
| String (UUID)
| Identificador único da tarefa gerado pelo sistema.

| `title`
| String
| Título descritivo da tarefa.

| `description`
| String
| Descrição detalhada da tarefa (opcional).

| `status`
| String
| Status atual da tarefa.
|===

== Códigos de status
A API utiliza os códigos de status HTTP padrão para indicar o sucesso ou falha das operações:

|===
| Código | Descrição

| `200 OK`
| Requisição realizada com sucesso.

| `201 Created`
| Tarefa criada com sucesso.

| `400 Bad Request`
| Parâmetros inválidos ou corpo da requisição malformado.

| `404 Not Found`
| A tarefa solicitada não foi encontrada.

| `500 Internal Server Error`
| Ocorreu um erro interno no servidor.
|===

== Observações
* A API trafega dados exclusivamente em formato JSON (`application/json`).
* Os IDs das tarefas seguem o formato UUID v4.
